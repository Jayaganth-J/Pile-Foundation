# C.C. Pile Foundation Website

Premium React website for C.C. Pile Foundation, built with Vite and modern animation patterns.

## Stack

- React
- Vite
- Framer Motion
- React Icons

## Sections Included

- Sticky navigation with mobile menu
- Hero with parallax motion and call to action
- About section with animated counters
- Services cards with hover interactions
- Projects gallery with overlay effects
- Why Choose Us highlights
- Contact details, quote form, and embedded map
- Responsive footer

	npm install

	npm run dev
3. Build for production:
	npm run build
